# Snake 97

Un videojuego Snake para PC inspirado en los teléfonos Nokia clásicos.

## Ejecutar

Necesitas Python 3 con Tkinter instalado.

```powershell
py -3 main.py
```

## Controles

- Flechas: mover la serpiente
- Espacio: pausar o continuar
- R: reiniciar la partida

El objetivo es comer la comida, crecer y conseguir la mayor puntuación posible sin chocar con las paredes ni contigo mismo.
